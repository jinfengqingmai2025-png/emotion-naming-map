# Contributing

Thank you for helping improve Emotion Naming Map.

## Before opening a pull request

1. Run `npm run validate`.
2. Explain what changed and why.
3. Keep safety language non-clinical and avoid promises to diagnose, treat, cure, or prevent a condition.
4. Never include real people's private health information, journal entries, or crisis disclosures.

## Content changes

Content changes should be small and reviewable. Please explain whether a change improves clarity, accessibility, translation quality, or grounding safety. The maintainer reviews authored content separately from the MIT-licensed code.

## Scope

This project is for education and self-reflection. Contributions that turn it into a diagnostic, crisis-triage, or medical-decision system are out of scope.
