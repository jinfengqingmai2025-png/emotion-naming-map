# Safety and security

## Scope

This repository is an educational self-reflection tool. It is not a medical device, diagnostic system, psychotherapy service, or crisis-response system.

Do not use it to make clinical decisions or to assess whether someone is safe.

## Reporting a technical issue

For a reproducible security or privacy issue in the software, open a private report to the maintainer before publishing exploit details. Do not include private journal entries, health information, API keys, or other sensitive data in an issue.

## Crisis boundary

If someone may harm themselves or another person, stop using the tool and contact local emergency services or an appropriate crisis service.
